URL
---
URL is an acronym for Uniform Resource Locator and is a reference 
(an address) to a resource on the Internet. ... Protocol identifier: 
For the URL http://example.com , the protocol identifier is http . Resource name: 
For the URL http://example.com , the resource name is example.com .


Port number is used to communicate to other system. If we dont specify the port number then default
port number is taken

http - 80
https - 443
smtp - 25
ssh - 22


syntax - protocol://hostname:portNumber/pathofResource

Ex - https://www.example.com:80/myFolder/myfile.html



Http Class
----------
Use the Http class to initiate an HTTP request and response.

Namespace
System

Http Methods
The following are methods for Http. All are instance methods.

send(request)
Sends an HttpRequest and returns the response.
toString()
Returns a string that displays and identifies the object's properties.



HttpRequest Class
------------------
Use the HttpRequest class to programmatically create HTTP requests like GET, POST, PATCH, PUT, and DELETE.
Namespace
System

Usage
Use the XML classes or JSON classes to parse XML or JSON content in the body of a request created by HttpRequest.

HttpRequest Methods
The following are methods for HttpRequest. All are instance methods.

getBody()
Retrieves the body of this request.
getBodyAsBlob()
Retrieves the body of this request as a Blob.
getBodyDocument()
Retrieves the body of this request as a DOM document.
getCompressed()
If true, the request body is compressed, false otherwise.
getEndpoint()
Retrieves the URL for the endpoint of the external server for this request.
getHeader(key)
Retrieves the contents of the request header.
getMethod()
Returns the type of method used by HttpRequest.
setBody(body)
Sets the contents of the body for this request.
setBodyAsBlob(body)
Sets the contents of the body for this request using a Blob.
setBodyDocument(document)
Sets the contents of the body for this request. The contents represent a DOM document.
setClientCertificate(clientCert, password)
This method is deprecated. Use setClientCertificateName instead.
setClientCertificateName(certDevName)
If the external service requires a client certificate for authentication, set the certificate name.
setCompressed(flag)
If true, the data in the body is delivered to the endpoint in the gzip compressed format. If false, no compression format is used.
setEndpoint(endpoint)
Specifies the endpoint for this request.
setHeader(key, value)
Sets the contents of the request header.
setMethod(method)
Sets the type of method to be used for the HTTP request.
setTimeout(timeout)
Sets a timeout for the request between 1 and 120,000 milliseconds. The timeout is the maximum time to wait for establishing the HTTP connection. The same timeout is used for waiting for the request to start. When the request is executing, such as retrieving or posting data, the connection is kept alive until the request finishes.
toString()
Returns a string containing the URL for the endpoint of the external server for this request and the method used, for example, Endpoint=http://YourServer, Method=POST

Exposing Apex Classes as REST Web Services
-------------------------------------------
You can expose your Apex classes and methods so that external applications 
can access your code and your application through the REST architecture.


Rest Context
--------------
1. This is a standard class defined in salesforce
2. It is defined under system namespace
3. This class contains the RestRequest and RestResponse objects

RestRequest
--------------
1. This is a standard class and defined under system namespace
2. This class contains all the data about the rest request message in Http request

RestRequest Properties
The following are properties for RestRequest.

Note

While the RestRequest List and Map properties are read-only, their contents are read-write.
You can modify them by calling the collection methods directly or you can use of the associated RestRequest 
methods shown in the previous table.

headers
Returns the headers that are received by the request.
returns the Map<String,String>

httpMethod
Returns one of the supported HTTP request methods.
Type : String
Values: GET, PUT, POST, PATCH, DELETE, HEAD


params
Returns the parameters that are received by the request.

Map<String,String>

remoteAddress
Returns the IP address of the client making the request.

requestBody
Returns or sets the body of the request.
requestURI
------------
Returns or sets everything after the host in the HTTP request string.


For example, if the request string is https://instance.salesforce.com/services/apexrest/Account/ then the requestURI is /Account/.

resourcePath
Returns the REST resource path for the request

For example, if the Apex REST class defines a urlMapping of /MyResource/*,
 the resourcePath property returns /services/apexrest/MyResource/*.

    global  static String deleteContact(){
        String result;
        RestRequest req=RestContext.request;
        RestResponse res=RestContext.response;
        Map<String,String> inputs=req.params;
        Id deletedContactId;
        String firstName=inputs.get('firstName');
        system.JSONGenerator js= JSON.createGenerator(true);
        js.writeStartObject();
        
        try{
            if(firstName!=null && firstName!=''){
                Contact con=[SELECT Id FROM Contact where FirstName=:firstName limit 1];
                deletedContactId=con.Id;
                delete con;
                js.writeStringField('Status','Deleted Successfully');
                js.writeStringField('Id',deletedContactId);
                js.writeObjectField('Contact',con);
            }
            
        }
        catch(Exception e){
            js.writeStringField('Status','Failed');
            js.writeStringField('ErrorMessage',e.getMessage());
        }
        js.writeEndObject();
        result=js.getAsString();
        system.debug('statusCode='+res.statusCode);
        system.debug('headers='+res.headers);
        return result;
        
    }

    @HTTPDelete
    global static List<ResponseWrapper> deleteContact() {
        // Initializing the response map
        List<Id> deleteContactIds=new List<Id>();
        List<Contact> deleteContacts=new List<Contact>();
        List<ResponseWrapper> resWrapperList=new List<ResponseWrapper>();
        Map<String, String> responseMap = new Map<String, String>();
        // Initializing the request parameter with the incoming request
        RestRequest req = RestContext.request;
        // Getting the request URI
        Map<String,String> contactRequestParams =req.params;
        //system.debug('contactId1='+contactRequestParams.get('contactId1'));
        deleteContactIds.add(Id.valueOf(contactRequestParams.get('contactId1')));
        deleteContactIds.add(Id.valueOf(contactRequestParams.get('contactId2')));
        deleteContactIds.add(Id.valueOf(contactRequestParams.get('contactId3')));
        // Initializing contact to delete
        for(Id ConId:deleteContactIds){
            deleteContacts.add(new Contact(Id=ConId));
        }
            
        // Deleting contact
        
            if(!deleteContacts.isEmpty()){
                Database.DeleteResult[] deleteResults= Database.delete(deleteContacts, false); 
                for(Database.DeleteResult delResult:deleteResults){
                    ResponseWrapper wrapper = new ResponseWrapper();
                    if(delResult.isSuccess()){
                        wrapper.status='Success';
                        wrapper.message='Record Deleted sucessfully '+delResult.getId();
                    }
                    else
                    {
                        for(Database.Error error:delResult.getErrors()){
                            wrapper.status='Error';
                            wrapper.message='error Fields='+error.getFields()+ 'Message is= '+ error.getMessage();
                        }
                    }
                    resWrapperList.add(wrapper);
                }
            }
        // Returning the response map in the response
        return resWrapperList;
    }

        req.setMethod('GET');

        {
            
            system.debug('getStatus='+res.getStatus());

            jsonString=res.getBody();

                if(jp.getText()=='USDINR'){
                    jp.nextToken();
                   INRValue=(Decimal)jp.getDecimalValue();
                }
            }
            
            
            List<PricebookEntry> pricebookEntries=[SELECT Id, Name, CurrencyIsoCode,INRValue__c, UnitPrice, ProductCode,
                                                   Product2Id, Pricebook2Id FROM PricebookEntry where
                                                   Pricebook2Id='01s0o00000Bd71MAAR' and CurrencyIsoCode='USD'];

    }
