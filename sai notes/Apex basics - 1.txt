Apex
----------------
Apex is a strongly typed, object-oriented programming language that allows developers to execute flow and transaction control statements on the Salesforce Platform server, in conjunction with calls to the API.

When Should I Use Apex?
The Salesforce prebuilt applications provide powerful CRM functionality. In addition, Salesforce provides the ability to customize the prebuilt applications to fit your organization. However, your organization may have complex business processes that are unsupported by the existing functionality. In this case, Lightning Platform provides various ways for advanced administrators and developers to build custom functionality.


Data Types
------------------
In Apex, all variables and expressions have a data type, such as sObject, primitive, or enum.
A primitive, such as an Integer, Double, Long, Date, Datetime, String, ID, or Boolean 
An sObject, either as a generic sObject or as a specific sObject, such as an Account, Contact, or MyCustomObject__c 
A collection, including:
A list (or array) of primitives, sObjects, user defined objects, objects created from Apex classes, or collections
A set of primitives 
A map from a primitive to a primitive, sObject, or collection (Maps)
A typed list of values, also known as an enum (Enums)
Objects created from user-defined Apex classes (Classes, Objects, and Interfaces)
Objects created from system supplied Apex classes
Null (for the null constant, which can be assigned to any variable)

9.Constants
Apex constants are variables whose values don’t change after being initialized once. 
Constants can be defined using the final keyword.

The final keyword means that the variable can be assigned at most once, either in the declaration itself, 
or with a static initializer method if the constant is defined in a class. 

public class myCls {
   static final Integer PRIVATE_INT_CONST = 200;
   static final Integer PRIVATE_INT_CONST2; 
 }

14. Do-While Loops

The Apex do-while loop repeatedly executes a block of code as long as a particular Boolean condition remains true

do {
   code_block
} while (condition);

Example
----------------
Integer count = 1;

do {
    System.debug(count);
    count++;
} while (count < 11);


15.For Loops

Apex supports three variations of the for loop:
The traditional for loop:

for (init_stmt; exit_condition; increment_stmt) {
    code_block
}

example
---------------------
for (Integer i = 0, j = 0; i < 10; i++) {
    System.debug(i+1);
}


The list or set iteration for loop:
for (variable : list_or_set) {
    code_block
}

example
----------------------

List<String> colors = new List<String>{
    'Yellow',
    'Red',
    'Green'};
        for(Integer i=0;i<colors.size();i++){
            system.debug('Color is='+colors[i]);
        }        


where variable must be of the same primitive or sObject type as list_or_set.
The SOQL for loop:
for (variable : [soql_query]) {
    code_block
}

or
for (variable_list : [soql_query]) {
    code_block
}

example
----------------------
for(Opportunity opty:[SELECT Id, Name,Account.name  FROM Opportunity])
   {
       system.debug('Opportunity Name='+opty.Name);
   }

17. Sets
A set is an unordered collection of elements that do not contain any duplicates. Set elements can be of any data type—primitive types, collections, sObjects, user-defined types, and built-in Apex types.

Example
-------------------------
// Define a new set
Set<Integer> mySet = new Set<Integer>();
// Add two elements to the set
mySet.add(1);
mySet.add(3);
// Assert that the set contains the integer value we added
System.assert(mySet.contains(1)); 
// Remove the integer value from the set
mySet.remove(1); 


18. Maps
A map is a collection of key-value pairs where each unique key maps to a single value. Keys and values can be any data type—primitive types, collections, sObjects, user-defined types, and built-in Apex types.

syntax

b. A class can contain variables and methods. Variables are used to specify the state of an object, such as the object's Name or Type. 20.Extending a Class

A class that extends another class inherits all the methods and properties of the extended class. In addition, the extending class can override the existing virtual methods by using the override keyword in the method definition.

Parent Class
-----------------------
public virtual class Bike {
    public virtual Integer gears(){
        return 4;
    }
    public virtual void ride()
    {
        system.debug('In normal bike');
    }
}

Child Class
--------------------------------
public class HeroBike extends Bike{

    public override  void ride(){
        system.debug('In hero ride');
    }
    
}

        Account acc2=new Account(Name=accName+' Test 2');

    public static void fetchOpportunities(){
        List<Opportunity>  oppList=[SELECT Id, Name,Account.name, Description FROM Opportunity];
        List<Opportunity> havingAccountNameRecords=new List<Opportunity>(); 
        List<Opportunity> havingNoAccountNameRecords=new List<Opportunity>(); 
        List<String> accountNames=new List<String>();
        for(Integer i=0;i<oppList.size();i++)
        {
            if(oppList[i].Account.name !=null){
                accountNames.add(oppList[i].Account.name);
                havingAccountNameRecords.add(oppList[i]);
            }
            else
            {
                havingNoAccountNameRecords.add(oppList[i]);        
            }
        }
        
        system.debug('accountNames='+accountNames);
        
        system.debug('List no account records='+havingNoAccountNameRecords);
        for(Integer i=0;i<havingAccountNameRecords.size();i++){
            system.debug('account Name ='+havingAccountNameRecords[i]);
            system.debug('accName records='+havingAccountNameRecords[i]);
        }
    }
    //Calling a test2 method from test1 method by passing integer as a parameter
    public static void test1(){
        Integer i=1;
        test2(i); //calling method
    }
